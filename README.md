# Config OVNI — kit Claude Code

La configuration Claude Code d'OVNI Conseil, en libre : skills, hooks, status line,
mémoire, vault Obsidian, Google, Micom, sous-agents. Sans aucune donnée personnelle.

**Le point d'entrée est `LISEZ-MOI.md`.** Le fichier `CLAUDE.md` du dossier sert de
pilote d'installation : Claude Code lit le kit et installe chaque brique une par une,
avec votre accord à chaque geste, sans rien écraser.

## Démarrer

```bash
git clone https://github.com/Valmartineau/config-ovni.git
cd config-ovni
claude
```

Puis dites à Claude : « installe le kit ».

Page de présentation : https://www.ovniconseil.fr/github

et de modification pour un usage pédagogique.
